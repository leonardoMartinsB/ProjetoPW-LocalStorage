## ✨ Sobre o Projeto

Este foi um dos **primeiros projetos de Programação Web**, no qual utilizamos pela primeira vez o **LocalStorage** do navegador.
O objetivo era **armazenar preferências do usuário** (como o modo claro/escuro 🌙☀️) e aplicar em um tema interdisciplinar: **Matemática do 1º ano**.

🔹 Principais destaques:

* ✅ Dark Mode & Light Mode com persistência via LocalStorage
* ✅ Estrutura organizada com **HTML, CSS e JS**
* ✅ Conteúdo inspirado nos temas estudados em sala (geometria, Pitágoras, porcentagem e gráficos)
* ✅ Primeira experiência prática integrando programação com outra disciplina
